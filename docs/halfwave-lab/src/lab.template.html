    The named storage — where a value lives between registers

    Every box is named storage on the die, read from its own wires each half-cycle: the API's alua, alub, idl, dor, abl, pclp fields and friends. A box lights when its value moved at this half-cycle. This is the layer the datapath tab's diagram rides on: the values that exist between the registers, which is where the 6502 does most of its thinking.
